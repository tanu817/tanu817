### NEMO — Digital Twin Autonomous System for Aquaponic Farms
*ROS 2 Jazzy · TurtleBot3 · Gazebo · SLAM · Python · Flask · Chart.js*

A 7-person TU/e Challenge-Based Learning project (aligned with UN SDG 2 and SDG 14) that pairs a physical TurtleBot3 robot with a live digital twin of a farm's nitrogen cycle.
- The robot navigates the farm autonomously using a TF2/Cartographer SLAM navigation layer
- The digital twin models ammonia toxicity and predicts ammonia cascade failures up to six hours ahead
- A web dashboard closes a two-way feedback loop with the farmer
- Built as a proof of concept and tested both in Gazebo simulation and on the physical robot in a lab setting
